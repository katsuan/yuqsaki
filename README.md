# 🧳 ゆくさき 〜YuQsaki〜

旅やおでかけの予定・場所・持ち物を、1つのしおりにまとめるツール。名前は「ゆくさき」（行く先）。英字は YuQsaki（「ゆ・く・さき」の「く」を Q にする。おくるん＝OQRN・つづく＝TsuduQ と同じ作り方）。キャッチコピーは「ゆく先を、ひとつのしおりに」。GitHub Pages でそのまま動く静的サイトで、サーバーは使わない。

公開URL: https://katsuan.github.io/yuqsaki/ （2026-10-23 公開。ConneQt の一覧・ポートフォリオにも載せた）

もとは沖縄旅行のしおり（`~/GitHub/okinawa-trip-2026`。1つの旅行のために手で書いたページ）。それを、だれでも入力して作れる形にしたもの。

## できること

- 🧳 しおりを作る：行き先・名前、しるし（絵文字）、行く日・帰る日（14日まで）。「1泊2日」「日帰り」は日にちから出す。しおりはいくつでも作れて、上の丸いボタンで切りかえる
- 見出し：出発まで「あと◯日」、旅行中は「◯日目」、終わったら「おかえり」
  - ⏳ くろのす：出発の日までのカウントダウンをくろのす（`https://katsuan.github.io/countdown/?type=until&date=…&title=…&emoji=…`）で開く
- 🗓 日ごとの予定：1日目・2日目…のタブ。予定は時刻（なくてもよい）・しるし（見る・ごはん・休む・買う・宿・車・電車・飛行機・温泉・遊ぶ）・名前・場所・メモ。時刻のあるものは時刻順、ないものは後ろ
  - 場所を押すと Google マップで探す（場所がなければ予定の名前で探す）
  - 右の丸は「行った・済んだ」のしるし
  - 名前を押すと直せる。直す画面から「この予定をカードで送る」（おくるんのマーク）でおくるんの「場所・予定」（`/plan/?tab=calendar&title=…&start=…&location=…&mapUrl=…`）を開ける。消すとき（`この予定を消す`）はすぐ消して「元に戻す」で戻せる
- 🎒 持ち物：チェックリスト。よくある持ち物（着がえ・充電器・保険証…）は押すだけで足せる
- 📤 みんなに渡す
  - 🔗 しおりのリンクを送る：しおりをまるごと縮めて URL の `#s=` のあとに入れる（`js/share.js`。deflate → base64url。`#` のあとはサーバーに送られない）。スマホは共有シート、なければコピー。受けとった人が開くと、その人の端末にしおりが入る（同じしおりがあれば新しいほうで上書き。「元に戻す」あり。済み・持ち物のチェックは受けとった人のものを残す）
  - 💬 LINE にカードで送る：おくるんのお知らせカード（`OQRN.cardUrl`）に、日ごとの予定の一覧を渡す。色はロゴの海の色（#12A0B0）。しおりのリンクが 1000 文字以内（LINE のボタンに入る長さ。予定10件くらいまで）ならボタンは「🧳 しおりを開く」、長ければゆくさきのページを開き、その旨を小さく出す。流入口は `from=yuqsaki`
- 🔒 控え：書き出し・読みこみ（同じしおりは新しいほう、ほかは足す）、このしおりを消す（元に戻せる）

## 記録の置き場所

この端末（ブラウザ）の localStorage の `yuqsaki:v1` だけ。サーバーには送らない。

- `trips`：`[{ id, title, emoji, start, end, items, bring, upd }]`
  - 予定 `items`：`{ id, day（0 から）, time（"HH:MM" か ""）, kind, title, place, memo, done }`
  - 持ち物 `bring`：`{ id, name, done }`
- `current`：開いているしおりの id
- リンクで渡すときは `done` を外す（`shareable()`）

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html`・`style.css` | 画面と見た目（スマホ前提。日付・時刻の欄は iPhone でずれないよう appearance をなくし、列は minmax(0, 1fr)。入力欄は 16px 以上）。部品はおくるんの Q キット。`style.css` には、ゆくさきの色と、ゆくさきにしかない見た目だけ |
| `app.js` | 操作（しおり・予定・持ち物・渡す・控え・リンクで受けとる） |
| `js/store.js` | しおりの保存・日付の計算・受けとったしおりの入れ方・控え |
| `js/share.js` | しおりをリンクに詰める・取り出す |
| `tools/icon.py` | アイコン・ロゴ・OGP |

## アイコン・ロゴ・OGP

`python3 tools/icon.py` で作る（図形を描く部分は、となりのおくるん（`~/GitHub/q-oqrn`）の `tools/brandkit.py`）。

- Q は地図のピン：白い輪の中に行き先のピン、右下へのびるしっぽは道のりの点と、着いた先の丸
- 色は海の青緑（ほかの Q のツールと重ならない色）

## 公開するときにすること

1. GitHub に `katsuan/yuqsaki` を作って push し、Pages を開く
2. 確かめがすんだら `index.html` の noindex を外す
3. おくるん（line-share）の `data/hub-links.json` に `key: "yuqsaki"` を足す（グループは「家族・記念日」か、新しく「おでかけ」）。`next` で、くろのす（出発まで数える）をおすすめにできる。`backup/app.js` の一覧に `["yuqsaki:", "ゆくさき", "yuqsaki"]` を足す
